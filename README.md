# StudySync – Smart Student Study Companion

StudySync is a smart and user-friendly study management web application designed to help students organize their academic activities, manage study time, track progress, and improve productivity.

## ✨ Features

### 📊 Dashboard
- View total study tasks.
- Track completed tasks.
- Monitor focus sessions.
- Check overall task completion percentage.

### 📚 Study Planner
- Add daily study tasks.
- Select subjects and deadlines.
- Mark tasks as completed.
- Delete unwanted tasks.
- Automatically save tasks using Local Storage.

### ⏱️ Focus Timer
- 25-minute Pomodoro timer.
- Start, pause and reset options.
- Track completed focus sessions.

### 🧠 Quiz Zone
- Interactive multiple-choice questions.
- Instant answer feedback.
- Automatic score calculation.
- Restart quiz option.

### 🎯 Progress Tracker
- Visual progress bar.
- Automatic completion percentage.
- Track your learning journey.

### 💡 Daily Motivation
- Daily motivational messages.
- Encourages consistent learning.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactivity
- Local Storage – Saving study tasks

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start organizing your study activities!

## 🎯 Project Objective

The main objective of StudySync is to make student life more organized and productive through a simple digital study companion.
